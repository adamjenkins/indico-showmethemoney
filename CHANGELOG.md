# Changelog

## 0.1.0 (unreleased)

- First release. Adds a **Require payment** switch to protected event menu
  entries, withholding them from registrants whose registration has not reached
  the *Completed* state.
- Blocked users are told why: a message box on every event page, and the same
  message with a payment link if they open the page's URL directly.
- Covers custom pages and links that are protected in their own right. Managers,
  speakers, admins and anyone the access control list admits for another reason
  are unaffected.
